### Bug fixes

- **A copy that someone edited stays when its update failed before it began.** When Nextcloud refused to write the new content of a document into its copy, for a full quota, a locked file or a missing permission, the app still took the copy as its own, and a later run wrote the content of Paperless over an edit of it, also with *Skip and report conflict*. Such a copy now keeps its fingerprint, and the run reports the edit as a conflict and leaves the file.
- **A Paperless URL that redirects is named as such.** A URL that leads to a redirect, such as from `http://` to `https://` or from an old name to a new one, looked like a token that Paperless refused, and an upload through it reached Paperless without its file and failed after six attempts without a cause. Paperless Sync now follows no redirect: *Test connection*, a run and an upload say where the redirect leads and which URL to enter. A URL whose redirect the mirror followed so far has to be changed to that address.
- **The app names the databases that it supports.** The app info declares SQLite, MySQL or MariaDB, and PostgreSQL, so that Nextcloud and the App Store no longer offer it for Oracle, whose tables can't take the rows of the app.
