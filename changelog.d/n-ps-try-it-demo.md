### Features

- **Try it in a few minutes:** `docker compose -f demo/compose.yaml up` starts Nextcloud with Paperless Sync and a Paperless-ngx with a made-up household archive on your machine alone, connects them with a dry run first and then the first run, and prints where the archive is. It makes its own password, keeps every port on `127.0.0.1`, and runs on Linux and on Docker Desktop for Windows and macOS. The README and the website show it under *Try it*.
