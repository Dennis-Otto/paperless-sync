### Features

- The administrator can set for each user which tags of Paperless they may see, in *Tags that a user may see*: such a user gets every document with at least one of their tags in an archive of their own, whoever owns it, and no other document, also with *The target user, all of them*, while the target user and every user without a line keep seeing what they saw before. A document that gains or loses one of the tags reaches or leaves their archive with the next run or the webhook, and Paperless Unified Search reads the same lines (#426).
