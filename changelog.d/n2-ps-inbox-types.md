### Features

- **The inbox keeps videos, programs and archives out of Paperless:** a video, a program or an archive in the inbox of Paperless Sync, such as after a clean-up of a computer that moved a whole folder there, no longer goes to Paperless. The file stays where it is, and the report of each run names it as *Set aside*, on the settings page, in the status and on the command line, until you move or delete it. Every other file goes to Paperless as before, however many there are, and a file that Paperless already has keeps working as it did.
