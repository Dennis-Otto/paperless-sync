### Features

- **The path template knows the placeholders of Paperless's own file names:** a `PAPERLESS_FILENAME_FORMAT` or a storage path of Paperless works with fewer changes now. `{{ doc_pk }}` gives the ID in seven digits, such as `0000123`, `{{ original_name }}` the name of the uploaded file, as `{{ original_filename }}` does, and `{{ created_month_name_short }}`, `{{ added_year_short }}`, `{{ added_month_name }}` and `{{ added_month_name_short }}` the parts of the dates, with the names of the months in the language of Nextcloud. A custom field may be written as Paperless writes it, `{{ custom_fields|get_cf_value("Invoice number") }}`, and with a default for a document without a value, `{{ custom_fields|get_cf_value("Invoice number", "none") }}`; a button under the template inserts it. Another filter of Jinja, such as `{{ title|upper }}`, isn't saved, and the settings name it. Every template saved before gives the same paths as before, so no file moves.
