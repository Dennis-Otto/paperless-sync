### Features

- **Each document can follow its storage path of Paperless:** turn on *Use the storage path of a document in Paperless* in *3 · Structured archive*, and a document with a storage path goes below the archive folder to the path of its template, as Paperless files it, with the marker `[P123]` and its extension; every other document follows the path template as before. A storage path whose template uses logic of Jinja, another filter, a variable that the path template doesn't know or a custom field that Paperless lacks keeps its documents with the path template, and the report of each run and dry-run, and the preview under the template, name it. So do they for a storage path that the account of the app can't see, by its ID, such as `#9`: share it with the account in Paperless. The preview and a dry-run take the switch before you save, and turning it on or off moves the copies as a new template does: each stays the same file, with its shares. The switch is off by default, so no file moves with the update. With it on, the setup of the account of the app grants View for Users and for Custom Fields as well, which the template of a storage path may use.
