### Bug fixes

- **A deleted Nextcloud user leaves nothing behind.** When an administrator deletes a user in Nextcloud, Paperless Sync removes their line of **Tags that a user may see**, the lines of **Paperless users with another Nextcloud ID** that name them, and what the app kept of their archive, their inbox and the files that they sent to Paperless. Before, all of it stayed until someone saved the settings again, and a new account with the same ID got the documents of the old line. The documents of a Paperless user whose line named the deleted user now go by the usual rule, to the Nextcloud user with the same ID or else to the target user: give that Paperless user a new line or another owner in Paperless. When the deleted user is the target user, the administrators get a notification that every run fails until the settings name another target user.
