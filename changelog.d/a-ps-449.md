### Features

- **A monitor reads the health of the mirror with a token that opens nothing else.** The new section *Health check for a monitor* on the settings page creates a token for Uptime Kuma, Home Assistant or any other monitor, shows it once beside the *Health check URL*, `/index.php/apps/paperless_sync/api/v1/health`, and revokes it again. The monitor sends it as `Authorization: Bearer <token>` and gets whether the mirror is healthy, its health, the state of the last run, the last success and the runs that failed in a row, without the error of a run and without an app password of an administrator, which opens every file and the administration of Nextcloud. A wrong token is refused and slowed down as for the webhook. The status API for administrators stays as it is; the guide shows the token in its examples for `curl`, Uptime Kuma and Home Assistant.
